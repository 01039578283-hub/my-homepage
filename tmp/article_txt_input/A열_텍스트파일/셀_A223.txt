와와학습코칭센터 송촌점은 송촌동 학생들에게 “성적을 올리는 학습 습관”을 만들어 주는 영어·수학 전문 학습코칭 센터입니다. 단순 문제풀이에 그치지 않고, 현재 수준 진단 → 취약 파트 처방 → 꾸준한 점검(피드백)까지 연결해 학습 전략을 완성합니다. 목표(내신/학년/상위권 도약)에 맞춘 맞춤 로드맵으로, 왜 틀리는지부터 해결하는 수업을 제공합니다.

우리 학원을 선택해야 하는 이유
1) 진단 기반 맞춤 학습코칭: 수업 전 학습 상태를 파악해 약점을 정확히 잡습니다. 
2) 영어·수학 “원리-적용-점검” 구조: 개념 이해 후 문제 적용, 오답/성취 점검으로 고쳐갑니다. 
3) 학습 습관 관리: 숙제·복습·오답 정리를 루틴으로 설계해 성적이 남도록 돕습니다. 
4) 학생 수준별 수업: 속도와 난이도, 문제 유형을 학년/실력에 맞춰 조절합니다. 
5) 지속적인 피드백: 단순 진도만이 아니라 성적 상승에 필요한 행동을 함께 설계합니다.

수업 대상 학생 & 학년별 학습 고민
1) 초등(예비초~초6)
- 고민: 영어 기초가 흔들림(단어/문장/기본 문법), 수학 계산 실수와 문제 이해력 저하
- 목표: 기초 개념 정리 + 반복 훈련 + 유형 적응으로 자신감을 회복

2) 중등(중1~중3)
- 고민: 내신이 불안(서술형/단원별 편차), 수학은 문제는 풀지만 성적이 안 나옴
- 목표: 단원 핵심 개념 강화 + 유형별 풀이 전략 + 오답 기반 재학습

3) 상위권/성적 상승 희망 학생
- 고민: 상위권 변별 문제에서 막힘, 시험 직전에도 점수 편차가 큼
- 목표: 심화·변형 유형 훈련 + 실수 관리 + 시험형 풀이 루틴 고도화

과목별 선택 기준(영어/수학)
1) 영어를 선택해야 하는 학생
- 단어·문장 암기가 잘 안 됨
- 문법/독해가 섞이면서 점수가 떨어짐
- 내신 서술형/서답형 대비가 필요함
- 듣기/읽기/쓰기 중 특정 영역이 유독 약함

2) 수학을 선택해야 하는 학생
- 계산 실수로 감점이 잦음
- 개념은 아는데 응용문제에서 막힘
- 단원별 이해도 편차가 커서 성적이 흔들림
- 오답을 반복해도 개선이 잘 안 됨(같은 실수를 반복)

3) 영어·수학 동시 선택이 좋은 경우
- 한 과목만이 아니라 전체 성적이 함께 올라야 하는 학생
- 내신 시즌에 맞춰 학습 계획을 안정적으로 잡고 싶은 학생
- 수학/영어 모두 “어디서 틀리는지”부터 잡아야 하는 학생

자주 묻는 질문(FAQ)
Q1. 입학 전 어떤 방식으로 실력을 확인하나요?
- 학습 상태를 파악하기 위한 진단(수업 전 점검)을 진행하고, 결과를 바탕으로 영어·수학 학습 전략을 설계합니다.

Q2. 수업은 내신 대비가 중심인가요, 선행도 하나요?
- 내신 대비를 기본으로 하되, 학생 수준에 맞춰 기초 보강 또는 다음 단계 선행이 필요하면 단계적으로 진행합니다.

Q3. 숙제/복습은 어떻게 관리되나요?
- 숙제는 수업 내용과 연동해 처방하고, 복습·오답 정리를 루틴으로 관리해 “다음 시험에서 점수로 이어지게” 돕습니다.

Q4. 수학이 약한데 어떤 부분부터 잡아야 할까요?
- 보통 개념-유형-오답의 연결이 끊긴 경우가 많습니다. 와와학습코칭센터는 틀린 원인을 기준으로 취약 파트를 우선 보완합니다.

Q5. 학년이 다른데도 반 구성이나 진도가 달라지나요?
- 학년/수준에 맞춰 수업 속도와 난이도를 조절하며, 학생별 목표에 맞춘 학습 로드맵으로 진행합니다.
