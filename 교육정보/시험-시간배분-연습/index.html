02 · 실행하기

무엇을 어떻게 해 볼까요?

1. 연습 시간과 사용할 자료를 먼저 확정하세요

학교에서 안내한 시험 범위와 시간, 문항 형식을 확인하고 그 범위에 맞는 자료를 고릅니다. 실제 시험 구성이 확인되지 않았다면 임의로 만든 연습 세트임을 구분하세요. 다른 학교나 과거 시험의 문항 수와 배점을 현재 시험의 확정 정보처럼 사용하지 않습니다.

연습 전에는 시작·종료 시각, 사용할 도구, 답안을 적을 위치를 정합니다. 해설을 가리고 진행하되 허용 도구는 학교 안내를 기준으로 합니다. 전화나 다른 일정으로 중단되었다면 기록에 남기세요. 중간에 멈춘 연습의 소요 시간을 중단 없이 푼 결과와 그대로 비교하지 않습니다.

연습 시작 전 기록

‘자료: 배운 범위의 연습 문제 / 제한 시간: 직접 정한 40분 / 답안 위치: 별도 종이 / 중단 여부: 없음’처럼 적습니다. 마친 뒤 실제 종료 시각도 함께 남깁니다.

2. 문제마다 초를 재기보다 중간 확인 지점을 정하세요

처음부터 모든 문항에 같은 시간을 배분하면 읽기 분량과 풀이 단계가 다른 문제를 반영하기 어렵습니다. 전체 시간을 첫 풀이, 보류 문제 재검토, 답안 확인으로 나누어 가안으로 적어 보세요. 어떤 비율이 자신에게 맞는지는 실제 연습 기록을 보고 조정합니다.

시계를 지나치게 자주 보느라 흐름이 끊긴다면 몇 개의 구간 끝에서 경과 시간을 확인합니다. 문항 묶음이나 지문이 끝난 지점처럼 찾기 쉬운 곳을 고르세요. 구간별 기록은 느린 이유를 찾기 위한 자료이지, 정해 둔 시간에서 조금 벗어났다고 연습을 실패로 판단하는 기준은 아닙니다.

40분 연습의 배분 예시

‘첫 풀이 28분 / 보류 문제 8분 / 답안 확인 4분’으로 시작해 볼 수 있습니다. 이는 고정 비율이 아니며, 서술형 분량이나 자신의 실제 소요 시간에 따라 다음 연습에서 바꿉니다.

3. 막힌 문제에는 상태를 남기고 돌아올 순서를 정하세요

한 문제에서 오래 멈췄을 때는 계속 읽기만 하는지, 다음 풀이를 실제로 진행하고 있는지 살펴봅니다. 접근 방법이 떠오르지 않는 문제와 계산의 끝만 남은 문제는 상태가 다릅니다. 연습 중에는 문제 번호 옆에 현재 상태를 짧게 남기고 다시 볼 순서를 정해 보세요.

보류한 문제를 잊지 않도록 표시하되 실제 시험에서는 허용된 방법을 따릅니다. 건너뛰었다면 답안 번호가 밀리지 않았는지도 확인하세요. 연습 자료에 정답을 표시할 공간과 답안을 제출할 공간을 구분해 보면, 알고도 답안을 빠뜨리는 상황을 점검할 수 있습니다.

보류 상태를 나누는 예시

‘△: 두 선택지 비교 필요 / 계산: 마지막 정리만 남음 / ?: 접근 방법 미정’처럼 자신이 구분할 수 있는 표시를 씁니다. 남은 시간과 해결 가능한 단계를 보고 돌아갈 순서를 정합니다.

4. 종료 전에는 풀이 검토와 답안 확인을 나누세요

검토 시간에 모든 문제를 처음부터 다시 풀려고 하면 답안 누락을 확인할 시간이 부족할 수 있습니다. 먼저 빠진 문항과 번호, 요구한 단위와 항목 수를 확인하고, 다음으로 근거가 불확실하거나 계산 점검이 필요한 문항을 살펴보세요. 실제 답안 작성 방식에 맞추어 연습합니다.

처음 답을 바꿀 때는 막연히 불안해서인지 새 근거를 찾았기 때문인지 구분해 보세요. 정답을 절대 바꾸지 않거나 반드시 바꾸라는 일률적인 규칙보다 지문·조건·계산에서 확인한 이유를 기준으로 판단합니다. 연습 종료 뒤에는 바꾼 답과 그 이유를 분석할 수 있게 남깁니다.

종료 전 확인 순서

‘미응답과 번호 확인 → 서술형 요구 항목 확인 → 표시한 계산·근거 검토’ 순서로 진행해 봅니다. 시간이 부족했다면 무엇을 확인하지 못했는지도 종료 뒤 적습니다.

5. 채점 뒤에는 시간과 정답 여부를 함께 비교하세요

연습이 끝나면 점수와 함께 오래 걸린 구간, 보류한 문제, 검토하지 못한 항목을 봅니다. 틀린 문제라도 개념을 몰랐는지, 시간에 쫓겨 조건을 놓쳤는지에 따라 다음 과제가 다릅니다. 맞혔지만 같은 내용을 여러 번 읽느라 오래 걸린 문제도 확인 대상입니다.

다음 연습에서는 바꿀 행동을 한두 가지로 좁힙니다. 개념이 부족하면 해당 내용을 복습하고, 답안 작성 시간이 부족했다면 확인 시간을 다시 배분하세요. 같은 문제의 답을 기억해서 빨리 푼 결과만으로 판단하지 말고 비슷한 범위의 다른 자료에서도 적용해 봅니다.

다음 연습 변경 사항

‘한 지문에 오래 머묾: 근거 위치 표시 연습 / 답안 두 개 누락: 구간 끝에 번호 대조’처럼 기록합니다. 새 모의 문제를 계속 추가하기 전에 이번 기록에서 정한 과제를 먼저 확인합니다.

05 · 함께 돕기

적용할 때 확인하세요

전체 시험 시간을 문항 수로 나눈 값을 모든 문항의 적정 시간으로 정하지 않습니다.

자주 묻는 질문

시간배분 연습은 매일 해야 하나요?

정해진 횟수는 없습니다. 배운 내용을 점검할 자료와 연습 결과를 검토할 시간이 있을 때 진행하세요. 복습할 내용이 쌓여 있다면 새 세트를 푸는 횟수보다 남은 과제를 먼저 조절합니다.

한 문제에 몇 분까지 써야 하나요?

문항 형식, 배점, 전체 시간과 현재 풀이 상태에 따라 달라집니다. 모든 문제에 같은 제한을 적용하기보다 연습에서 오래 멈춘 문항을 확인하고 보류 기준을 정해 보세요.

제한 시간이 끝나도 계속 풀어 봐도 되나요?

학습을 위해 이어 풀 수는 있지만 제한 시간 안의 답안과 이후 풀이를 구분해 기록하세요. 채점 결과도 나누어 봐야 내용 이해의 문제인지 시간배분의 문제인지 점검할 수 있습니다.
