# 겹치는 페이지의 역할 정비 — 2026-09-28

사용자 범위는 “겹치는 묶음에서 대표 1개를 그대로 두고 나머지만 개선”입니다. 사이트 전체를 다시 작성하지 않습니다. 기존 URL, canonical, 색인 정책, 원고 본문, 센터 정보와 이미지 속성은 보존합니다.

## 검토 범위

- 사이트맵 21,543개를 확인했습니다.
- 같은 지역·학교급·과목의 일반 과정 안내 5,936개 묶음을 분류했습니다.
- `고등학생/고등`, `중학생/중등`, `초등학생/초등`, `영수/영어수학`, 와와 브랜드 표기를 같은 주제로 비교했습니다. 일반 과정 안내의 `전문` 표기만으로 별도 목적이 되지는 않는다고 판단했습니다.
- `근처`의 이동 조건, `내신`의 시험 대비, 구체적 학년별 학습 계획은 별도 목적이 있어 합치지 않았습니다. 디렉터리·교육정보·학습가이드·후기·홈도 대상에서 제외했습니다.
- 실제 지점의 수강·위치 안내를 우선 대표로 남겼습니다. 지점 상세가 없는 묶음에서는 기존 과목별 기본 안내를 남기고, 영수/영어수학 두 경로는 영어수학 경로를 남겼습니다. 브랜드 두 경로는 `/wawa/`를 남겼습니다. 검색 유입 실적에 따른 순위 판정은 아닙니다.

## 재생성과 검증

`page-overlap-plan.json`은 대표와 수정 대상의 고정 목록입니다. 새 대상을 자동으로 확장하지 않습니다. 기존 생성기를 다시 실행한다면 역할 정비 단계도 반영해야 하며, manifest만 무조건 갱신해 역할 변경을 되돌리지 마세요.

Python의 `lxml`을 사용합니다. 이번 실행의 원본 백업과 검증 자료는 공개 소스 밖의 `C:/Users/1992k/Desktop/CodexData/outputs/wawa-overlap-roles-20260928/`에 있습니다. 원본 작성용 checkout에는 반영하지 않았으며, 기존 변경분을 보존했습니다.

1. `improve_overlapping_pages.py --backup <before-targets.zip> --report-dir <검증 폴더>`는 검토한 원본에서 대상만 변경합니다. 현재 파일이 원본 또는 직전 적용 결과와 다르면 중단합니다. `--sample`은 23개 양식의 화면 검증용이며 최종 적용 범위가 아닙니다.
2. `audit_overlapping_pages.py --report-dir <검증 폴더>`는 전체 인벤토리 보존과 모든 대상의 제목·설명·스키마·현재 위치·새 링크·입력 양식을 확인합니다.
3. `finalize_overlap_release.py --report-dir <검증 폴더>`는 통과한 결과의 사이트맵과 public manifest만 갱신합니다.
4. 기존 Vercel 빌드인 `release-public-build.mjs → wawa-analytics-build.mjs → seo-descriptions.mjs`를 실행합니다. 역할 정비 코드는 서버에서 실행할 필요가 없는 정적 산출물입니다.

원고 본문과 이미지·센터 정보·canonical·robots의 보존을 적용 시 모든 파일에서 대조합니다. 문서 설명은 80자 이내이며 meta/OG/Twitter 및 페이지 스키마와 맞춥니다. 학습 양식의 입력 내용은 전송하거나 저장소에 남기지 않으며, 사용자가 눌렀을 때만 로컬 텍스트 파일로 내려받습니다.

이 변경은 콘텐츠 용도 구분이며 네이버 수집·색인·노출 회복을 보장하는 조치가 아닙니다. GitHub 푸시와 Vercel 공개 배포는 이번 로컬 변경·검증과 구분해서 기록합니다.
