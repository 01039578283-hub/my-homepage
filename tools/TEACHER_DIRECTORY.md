# 선생님찾기

사용자가 제공한 교사 프로필.xlsx의 네 열(지점, 가려진 이름, 학습 방향,
소개글)을 그대로 사용한다. 1,002행은 고유 인원 수가 아니다. 이름이 같은
행을 합치지 않고 원본 행 번호별 소개로 보존한다.

현재 지점 정보의 sourceName과 정확히 일치하는 지점만 주소와 지점 URL을
연결한다. 석사2호점과 주엽2호점은 주소를 추측하거나 석사점·주엽점으로
합치지 않는다. 기존에 제외한 W+·글로리드·대구역점2호관 11개 지점의
40행은 재공개하지 않는다. 기존 석사점에는 교사 소개 자료가 없으므로
새 소개 링크를 만들지 않는다.

사진은 사용자가 승인한 공용 소개 이미지다. 실제 교사 사진이라고
표시하지 않고 Person.image에도 연결하지 않는다. 제공한 작은 PNG
12개를 원본 그대로 복사하고, 지점마다 서로 다른 파일과 해시를 배정한다.

전체 기존 HTML은 메뉴 링크와 header.css 버전만 추가 변경한다.
지점·동네의 관련 소개 섹션은 실제 지점 경로 또는 기존 기관 이름과
실제 지점의 동네 정보가 함께 일치할 때만 추가한다. 원래의 원고,
이미지, canonical, robots, 상담 기록 양식, 후기, 메타데이터는 보존한다.
공통 메뉴 변경만으로 sitemap 날짜를 모두 바꾸지 않는다.

생성:
`python -X utf8 tools/build_teacher_directory.py --report-dir <teacher-report>`

검증:
`python -X utf8 tools/verify_teacher_directory.py --report-dir <teacher-report>`

원본 엑셀·사진 폴더는 변경하지 않는다. tools 폴더의 추출 자료 및 검증
도구는 공개 파일 manifest와 Vercel 산출물에서 제외한다. 학습가이드를
다시 생성한 뒤에는 이 생성기를 다시 실행해 메뉴를 유지한다.
