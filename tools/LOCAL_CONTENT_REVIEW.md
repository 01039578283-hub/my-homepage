# 동네·지점 본문 정리 (2026-10-19)

기존 URL·제목·이미지·지도·링크·구조화 데이터와 페이지 역할을 유지하며, 검토된 본문 텍스트와 기존 지점 정보 카드만 수정한다.

- `refine_local_content.py`는 과거 생성기의 정확한 연결 문구 목록만 읽는다. 일반적인 조건절을 임의로 제거하지 않는다.
- 본문 안에서 반복되는 전체 제목을 문맥에 맞게 줄인다. 제목, 링크 문구, 이미지 대체 설명, FAQ는 이 처리에서 제외한다.
- 교사 지도 방향은 `teacher-profiles-source.json`의 이미 공개된 소개 자료에서 가져온다. 현재 과목·학년 배정으로 해석하지 않는다.
- 학년별 안내는 `branch_course_guidance.py`의 보류 학년과 별도 확인 조건을 유지한다. 원본에 없는 개설 사실을 만들지 않는다.
- 지역별 가상 상황은 실제 학생의 사례와 구분한다. 같은 센터를 공유하는 동네의 사실을 임의로 달리 쓰지 않는다.

실행 전 운영 커밋과 원본 자료를 확인하고 전체 공개 페이지의 기준 목록을 만든다. 기본 실행은 변경 계획만 생성한다. 검토한 `review-plan.json`의 SHA-256을 `--apply`에 전달하면 해당 파일 해시가 일치하는 경우에만 적용한다. 새 백업 ZIP을 만들며 기존 백업은 덮어쓰지 않는다. 원본 작성용 폴더에는 적용하지 않는다.

적용 후 공개 manifest를 갱신하고 `node favicon-build.mjs` 전체 파이프라인을 실행한다. 전체 페이지의 URL·이미지·지도·메타정보·내부링크·구조화 데이터와 문구 반영을 검사하고, 모바일·PC 대표 화면과 기존 기능을 확인한다. 원격 main과 기준 커밋이 같은지 확인한 뒤 사용자가 승인한 범위에서 배포한다.

최초 검토·검증 산출물은 `CodexData/outputs/local-content-20261019`에 저장했다. 새 실행에서는 새로운 기준 목록과 별도 출력 폴더를 사용한다. 기존 생성기를 다시 실행하면 이전 문구가 재생성될 수 있으므로 동일 검토 절차를 다시 거친다.
